Getting started

Back to your timeline
in three steps.

  1. 01

    Download Flux.

    One file for Mac and Windows.
    Get the latest version ↗

  2. 02

    Install the extension.

    Save your work and close After Effects. Open the file with ZXP Installer ↗.

  3. 03

    Connect your account.

    Reopen After Effects. Find Flux under Window → Extensions, then connect in Settings → Account.

A few useful details.

What do I need?+

After Effects 2022 or newer and a supported ChatGPT or Claude account. For Claude, install Claude Code first. Windows support is currently in testing.

Does Flux use my own account?+

Yes. Connect your ChatGPT or Claude account from Flux. Your provider’s plan requirements and usage limits apply.

How do I update Flux?+

Open Settings → Updates in Flux. You can also get the latest version from GitHub Releases.
